# 标签资产库

面向 Chrome 121+、Edge 121+ 及其他 Chromium 浏览器的本地标签管理扩展。当前版本为 Chrome Web Store 发布候选版 0.7.0。

## 已实现

- 自动捕获标签标题、URL、窗口位置和打开状态。
- URL 规范化与精确去重，自动移除常见跟踪参数。
- 永久分组与域名、标题、URL 关键词规则。
- 标签栏、网页内容区和扩展图标右键加入永久分组。
- 永久分组新建、重命名、20 色标识和删除。
- 彩色折叠分组，展开后直接访问组内页面。
- 分组支持手动拖拽、名称、页面数和最近访问排序。
- 组内页面支持移出当前分组或移动到其他分组。
- 页面自定义显示名称，网页刷新后仍然保留。
- 根据浏览器 UI 语言自动切换中文或英文。
- 根据系统外观自动切换浅色或深色界面。
- 正式扩展 Logo 与 16/32/48/128px 浏览器图标。
- 当前打开、已休眠、已归档、重复页面和未分类视图。
- 手动休眠、归档、恢复及批量操作。
- 已归档资源支持从资源库和会话快照中永久删除。
- 三级渐进式休眠：当前窗口安全休眠、所有窗口安全休眠、所有窗口强力休眠。
- 闲置标签自动休眠，默认阈值为 30 分钟。
- 自动和手动会话快照。
- 按窗口、固定状态和浏览器标签组恢复会话。
- 本地全文搜索。
- JSON 完整备份、导入和合并。

状态说明：“已休眠”表示标签仍在浏览器标签栏，只卸载页面进程；“已归档”表示页面记录已保存到资产库，真实浏览器标签已经关闭，可随时从资产库重新打开。

所有业务数据保存在扩展自己的 IndexedDB 中，不上传网络。详细数据边界见 [隐私政策](./PRIVACY.md)。

## 安装

推荐从 [GitHub Releases](https://github.com/theZmemo/tab-vault-extension/releases) 下载 `tab-vault-*-extension.zip` 并解压。

从源码构建时，生产文件生成在：

```text
dist/
```

在 Chrome 中安装：

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `dist` 目录。
5. 点击浏览器工具栏中的“标签资产库”图标打开侧边栏。

Edge 使用 `edge://extensions`，其余步骤相同。

## 使用

### 创建分组

点击侧边栏顶部的“文件夹 +”按钮，输入名称并选择颜色。分组以彩色色条显示，点击色条展开组内页面，点击铅笔按钮可重命名、换色或删除。

### 加入分组

- 标签栏右键：`加入永久分组` → 选择分组。Chrome 149 及以上可用。
- 网页内容区右键：`加入永久分组` → 选择分组。
- 侧边栏批量操作：勾选页面 → 点击底部“文件夹 +” → 选择分组。

右键菜单会在新建、重命名或删除分组后自动更新。较旧 Chromium 不支持标签栏右键扩展菜单时，网页内容区和扩展图标右键仍然可用。

### 自动分组

展开导航，进入“规则中心”，按域名、标题关键词或 URL 关键词创建规则。保存时会重新匹配历史资源，新打开的页面也会自动进入对应分组。

点击插件后默认进入永久分组总览，直接查看彩色分组和组内页面；输入搜索词时切换为全库资源结果。“全部资源”保留为独立入口。侧边栏常驻 42px 图标轨道，展开后的 208px 分组面板覆盖显示，不压缩主列表。

- 图标轨道保留前 7 个快捷分组，点击图标直接进入分组；分组更多时显示“更多分组”入口，点击后在覆盖面板中查看全部分组。
- 搜索同时匹配手工修改的名称、网页原标题、URL、域名和备注，支持连续中文标题任意位置的子串匹配；手工名称权重最高，已加入永久分组的资源优先展示。

### 排序与移动

- 分组标题区可选择手动排序、按名称、按页面数或按最近访问排序。
- 手动排序模式下，拖拽彩色分组条即可保存顺序。
- 组内页面右侧的双向箭头可将页面移动到其他分组，或从当前分组移除。

### 语言与侧位

- 扩展名称、界面、右键菜单和提示自动跟随浏览器 UI 语言；中文浏览器显示中文，其他语言默认显示英文。
- 界面深浅色自动跟随系统或浏览器颜色模式。
- 42px 图标导航轨道自动跟随浏览器侧边栏侧位，不提供无效的应用内侧位选项。
- Chrome 最外层侧边栏的位置和宽度由浏览器控制。设置页会显示当前侧位，并可打开 Chrome 外观设置；宽度需要拖动浏览器侧边栏分隔线调整。

### 重命名页面

点击资源标题右侧的铅笔按钮，修改资产库中的显示名称。该操作不会修改实际 URL 或网页原标题；需要恢复时，在重命名窗口点击“恢复原标题”。

## 默认行为

| 配置 | 默认值 |
|---|---:|
| 自动捕获 | 开启 |
| 自动休眠 | 开启 |
| 休眠阈值 | 30 分钟 |
| 会话快照间隔 | 5 分钟 |
| 恢复并发数 | 5 |
| 自动关闭归档 | 关闭 |

当前标签、固定标签、播放声音的标签、加载中的标签和已保护页面不会被自动休眠。归档操作始终先写入本地数据库，再关闭浏览器标签。

扩展无法识别网页中的未提交表单或 SPA 临时状态；包含此类内容的页面应设为“已保护”，或在休眠、归档前先完成保存。

手动批量休眠按影响范围逐级增强：

1. 第 1 级仅处理当前窗口的其他标签，保留全部安全保护。
2. 第 2 级沿用相同保护条件，扩大到所有窗口。
3. 第 3 级额外处理设置为不可自动丢弃的后台标签，但仍跳过活动、固定、播放声音、加载中、已保护和浏览器内部页面。

休眠只卸载页面进程并保留标签；归档会关闭真实标签，两者不会合并为同一级操作。

## 开发命令

```bash
npm install
npm run build
npm test
npm run test:extension
npm run test:locale
npm run verify:store
npm run render:store
```

`npm run test:extension` 会启动临时 Chromium 配置，验证自动捕获、去重、永久分组、规则、归档恢复和会话快照，不会使用日常浏览器配置。

`npm run verify:store` 会重新构建并检查 Manifest V3、版本、图标、权限、CSP、远程代码、调试端点和发布包文件类型。Chrome Web Store 字段及权限理由见 [发布资料](./CHROME_WEB_STORE.md)。

`npm run render:store` 会基于最新端到端截图生成 1280x800 商店截图和 440x280 小宣传图。

## 当前边界

- 仅保存 URL 和结构化元数据，不保存 Cookie、表单内容或网页运行状态。
- 完整 URL 可能包含查询参数或访问令牌，导出的 JSON 备份应作为敏感文件保管。
- 休眠或恢复页面时，未提交表单和 SPA 临时状态可能丢失。
- 浏览器配置目录损坏或卸载扩展会删除 IndexedDB；当前应定期导出 JSON 备份。
- SQLite、iCloud 加密备份、分组自动关闭归档和跨设备同步尚未实现。

完整产品与技术设计见 [设计方案.md](./设计方案.md)。
